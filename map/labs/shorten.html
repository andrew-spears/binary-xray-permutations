Pick an arrangement. Its word lists, for each stone from the lowest diagonal up, how far the stone is from its evenly spaced position. Each step replaces the marked piece by a shorter piece, until every letter is 0.

size n arrangement

Reading it upwards. The last board is solved by the anti-diagonal. The conjecture is equivalent to: whenever the shorter word has a solution, so does the longer one above it. The boards show one solution of each arrangement, found by search; nobody knows how to turn one solution into the next, and that is the open part.

ZERO drops a 0 that stands just before a −1. PEAK turns 1 0 −1 into 0. RUN takes a longer falling run that crosses zero, such as 2 1 0 −1, and removes one stone from it.
