## 0. Problem
BMPS 2005 Conj. 5 = Nordh 2008 Conj. 10 ("Perfect Skolem sets", Discrete Math 308, arXiv math/0506155). D = {d_1<…<d_n} ⊂ {−(n−1)…n−1} is a binary x-ray (some permutation π uses each diagonal π(i)−i in D exactly once — a **witness**; W(D) = #witnesses) ⇔ s_k = d_k + n − k is a Landau score sequence (Σ_{i≤k} s_i ≥ C(k,2), equality at n). Necessity known; sufficiency open as of 2026. Verified exhaustively n ≤ 22 (n ≤ 21 two independent programs, n = 22 one; Devin round 1).

Literature checked 2026-11-22 (agent; paraphrased via WebFetch, verify theorem numbers before citing): Li–Liu–Yao arXiv:2608.01442 (fractional result = Thm 1.7/Cor 4.4; facet description of the projected x-ray polytope via tropical hyperplane arrangements, Prop 3.4 — usable to screen candidate counterexamples; Sec. 5 limits, see §5); Davis–Schroeder arXiv:2606.21532 (map γ from witnesses to tournaments via transitive tournament decompositions, Thm 3.4; sufficient conditions for a reverse map δ, Lemma 3.5; δ can't be total, Example 3.7 scores (1,1,2,3,3); tight-cut block split stated as Lemma 2.4); Nordh 2017 note arXiv:1707.03928 (nothing new). Chaudhary–Khandelwal arXiv:2610.30058: not accessible. No other relevant 2020–2026 work found.

Example π = 2 4 1 3: diagonals {−2,−1,1,2}, s = (1,1,2,2).

## 1. Equivalent forms (all from d_k = s_k + k − n)
1. Placement: one point per diagonal in D, rows and columns distinct.
2. Rainbow matching: rows→columns perfect matching using exactly one edge of each offset in D.
3. Tournaments: a position rule maps witnesses to tournaments with the same scores; adds nothing to existence.
4. Fractional: doubly stochastic matrix with the diagonal sums always exists (Li–Yao). Conjecture = integrality.
5. Stones on a plank: n stones on marks −(n−1)…n−1; start = every other mark (transitive, W=1). Score = #empty marks to the left; Σs = C(n,2) ⇔ balance.
6. Skolem: rows at positions 1…n, columns at n+1…2n; witness = pairing of {1…2n} with lengths A = D+n. ΣA = n² forces every pair to straddle the middle. Nordh's parity condition is automatic; his density condition = Landau upper bound. (Skolem tab in the equivalent-views lab.)

- **Sum of two permutations / interface walk** (Devin 2026-11-23, agents/interface/): rows numbered from the bottom, the k-th smallest diagonal needs r′ + c = b_k = d_k + n + 1 = 2k + e_k, e_k = s_k − (k−1). Witness ⇔ b = ρ + γ with ρ, γ permutations ⇔ {1…2n} splits into pairs with the odd sums 2b_k − 1 ⇔ m_b occurs in m_δ². Landau slack σ_k = Σ_{i≤k} e_i; words: e_1 ≥ 0, e_{k+1} ≥ e_k − 1, σ_k ≥ 1 inside, σ_n = 0. After k stones the used rows/columns are a pair of partitions (λ, μ) with |λ| + |μ| = σ_k; a witness is a walk ∅∅ → ∅∅, step rule independent of k and n. Map: interface.

## 2. Proved
- **Tight prefix splits.** Equality at k<n ⇒ S splits into two smaller instances whose witnesses glue (= Nordh's skew sum). Only no-tight-cut D matter.
- **Mirror.** Transpose reverses the x-ray; check one of S, reverse(S). (Anti-diagonal reflection fixes the x-ray, so it isn't a symmetry to use.)
- **Minimal moves reach everything.** Minimal move (cover relation): stones a < b with a+1, b−1 empty and every mark strictly between occupied move to a+1, b−1 (scores v, v+2 → v+1, v+1). Moves with b = a+3 alone reach nothing from the start; several earlier experiments (paritydata move claims, first connect run, our repair radius) used only those. Each raises #3-cycles = C(n,3) − ΣC(s_k,2) by exactly 1 (graded). Proof by induction on 3-cycles: non-transitive S has a tie; take a maximal run of equal scores v at i..j, apply reverse move at its ends; prefix sums drop only on [i,j−1], none of which can be tight (tight at k forces s_k < s_{k+1}). Planar only for n ≤ 6.
- **Nordh's families** (arXiv v1 numbering):
  - F1 (Thm 28): D = {±1…±a}, n = 2a, always realizable. Witness: π(i) = 2i (i ≤ a), 2i−(2a+1) (i > a). Scores (a−1)^a a^a, no tight cut.
  - F2 (Cor 26(1), via Thm 22 + Shalaby's near-Skolem theorem): D = ±({1…k}∖{m}), n = 2k−2, realizable when k ≡ 0,1 (mod 4) and m odd, or k ≡ 2,3 (mod 4) and m even; the witness is an involution (a special case of F3). Example k = 4, m = 3: D = {±1,±2,±4}, π = 5 3 2 6 1 4. (Earlier note "k = 4, m = 2, D = {±1,±3,±4}" was wrong: that is P₆, realizable but not by this theorem.)
  - F3 (Thm 23, trivial equivalence): D = ±L has an involution witness ⇔ {1…2m} pairs with distances exactly L (similarly with one fixed point). Imports Skolem (L={1…m} iff m ≡ 0,1 mod 4) and Simpson 1983 (L={d…d+m−1}). Not every symmetric D has an involution witness: ±{1,2,3} has 6 witnesses, none involutions (but it has a centrosymmetric one, §3).
  - Direct sum (Thm 27): D₁ ∩ D₂ = ∅ ⇒ π₁ ⊕ π₂ witnesses D₁ ∪ D₂; can lack a tight cut (e.g. 21543; 2176543 = 21 ⊕ reversal₅). Usable reduction: 0 ∈ D and D∖{0} valid ⇒ fixed point at (1,1), recurse.
- **Inflation by a permutation σ** (trivial, generalizes direct sum σ=12 and skew sum σ=21): blocks π₁…π_k in block-row i, block-column σ(i) witness ⋃(D_i + offset_i), offset_i = column start − row start of block i, when disjoint. Example: 2413[1,1,21,21] = 3 6 2 1 5 4, D = {−3,−2,−1,0,2,4}, no tight cut.
  - **Read off from the x-ray alone:** D is such an inflation (given the conjecture at smaller sizes) iff D splits into groups G_i (sizes n_i) such that (a) each group's mean c_i is an integer (valid D_i sum to 0, so c_i = offset_i), (b) G_i − c_i passes Landau at size n_i, and (c) the weighted pattern is realizable: there are orders of the blocks by row and by column (σ) with c_i = (Σ sizes of blocks left of i's column) − (Σ sizes of blocks above i's row). (c) is itself a small weighted x-ray problem on k blocks. Deciding whether such a grouping exists is a search; no simple rule known.
  - Contracting one block shifts every other point's diagonal by +1 (above-right of the block), −1 (below-left) or 0, so the contracted σ depends on the witness, not on D — except for corner blocks (direct sums).

## 3. Computational facts (exhaustive unless noted)
- **Almost everything decomposes** (prime agent 2026-11-22, /home/claude/agents/prime/, rechecked n = 7, 10, 12): with σ of any size k < n (k = n with singleton blocks is excluded as trivial), every valid no-tight-cut D for 4 ≤ n ≤ 12 is an inflation except exactly one, P_n. Counts up to mirror: no-tight-cut 1, 3, 5, 15, 36, 107, 306, 969, 3055 for n = 4…12, primes 1 each. Measured via witnesses (decomposable ⇔ has a non-simple witness), so it relies on the conjecture at those sizes (verified). Smallest σ size needed at n = 12: 2: 936, 4: 380, 5: 383, 6: 461, 7: 428, 8: 240, 9: 155, 10: 54, 11: 17 (size 3 impossible; σ = 21 never, it gives a tight cut). Earlier coverage numbers (46% at n = 12) used only σ ∈ {12, 21, 2413, 3142, simple size 5} and are superseded.
- **P_n:** scores (1,1,2,3,…,n−3,n−2,n−2); D = {±(n−2)} ∪ {|d| ≤ n−3, d ≡ n−1 mod 2}; stones ○●●○●○…○●●○. Unique no-tight-cut D with the minimum number of 3-cycles (n−2). Exactly two witnesses (n ≤ 14), both simple; the second is the transpose (n even) or the 180° rotation (n odd). **Proved formula** (verify agent, /home/claude/agents/verify/pn.py, checked n ≤ 30): π(2) = n; π(i) = n−1−i for odd i ≤ n−2; π(i) = n+3−i for even i ≥ 4; π(n−1) = 1 (n even) or π(n) = 2 (n odd).
- **Symmetric D have symmetric witnesses** (parity-data agent 2026-11-22; sympair agent 2026-11-23, /home/claude/agents/sympair/): every valid D = −D has an involution witness for n odd ≤ 15 (1971 at 15) and a centrosymmetric witness (π(n+1−i) = n+1−π(i)) for n even ≤ 14. For even n, an involution witness exists exactly when L = D ∩ (0,∞) has an even number of even elements (n ≤ 14; necessity is a parity count), i.e. that case is Nordh's open Conj. 8 (parity + density ⇒ perfect Skolem set). Odd-count case: centrosymmetric witness ⇔ half-size labelling puzzle (σ ∈ S_m, each row labelled |σ(i)−i| or 2m+1−i−σ(i), labels = L). In L-terms Landau is: the K largest of L sum to ≤ K(n−K). Odd n: pairing of {1..n}∖{f} with distances L; no fixed f works, and parity+density for {1..n}∖{f} is not sufficient (n = 5, L = {1,3}, f = 3). No Skolem-literature theorem covers arbitrary L. (Corrected counts: involutions for even n missing for 109/223 at 12; centrosymmetric for odd n missing for 280/557 at 13.) Odd n reduces to pairing {1…n} minus one point with differences D ∩ (0,∞) (Skolem/Rosa type); even n to a similar half-size problem. Parity corollary: a working a with a(−d) = a(d)+d (odd n) or 1−a(d) (even n).
- **Parity choices** (same agent; witnesses n ≤ 13, LP n ≤ 10; convention a(d) = row mod 2): for every minimal move D → D′ (x, x+3 → x+1, x+2) some working a for D with a(x) = a(x+3) = u works for D′ with u on both new stones, all other values kept (n ≤ 11 witnesses, n ≤ 10 LP) — existence on both sides, so no induction; "every working a carries over" fails at n = 6 (D = (−4,−3,0,1,2,4), x = −3). Tight cuts: A(D) = A(low) × A(high) exactly. Exact symmetries: transpose a′(−d) = a(d)+d; 180° rotation a′(−d) = a(d)+n+1; anti-diagonal reflection a′(d) = a(d)+d+n+1 (so |A| is even except for the all-same-parity D, the only D with a unique choice). Canonical rules all fail by n = 6 (alternating within parity classes: n = 6, D = (−4,−2,0,1,2,3); all functions of 4 binary local features). A_wit = A_lp for n ≤ 7, first differ at n = 8. #D with |A_wit| = 2^j equals C(n−1, 2j) for j ≤ 3, n ≤ 12 (unexplained).
- **Witness ratio.** min W(after)/W(before) over minimal moves = 2/3 for n ≤ 16, attained only by ●●○●○●● → ●○●●●○●. Next-smallest: 0.75 (n=11), ≈0.737 (12,13), ≈0.734 (14–16). A positive lower bound for all n proves the conjecture.
- **G1, one deleted column** (Devin; sufficient for m ≤ 15). Rows 1…m, columns {1…m+1}∖{c}, t_k = d_k + m − k: placement ⇔ Σ_{i≤k} t_i ≥ C(k,2) + max(0, k+1−c), equality at m. G1 at n−1 ⇒ conjecture at n (largest diagonal goes in row 1, column 1+d_n): **proved** (verify agent; the re-indexed scores equal s_k, and for k > d_n the slack is Σ_{j=k+1}^{n−1}(j − d_n) ≥ 0). So G1 for m ≤ 15 gives the conjecture for n ≤ 16 only. See §4.6.
- **Parity-refined LP on boards with h deleted columns** (subagent, 2026-11-22; scripts /home/claude/agents/holes/). Rows 1…m, columns {1…m+h} minus h. Condition: there is a choice of row parity a(d) for each d ∈ D such that (i) the parity counts match rows and columns, and (ii) the fractional placement LP restricted to cells with r ≡ a(d) is feasible. This is exact (⇔ placement) for h = 2 (m ≤ 10), h = 3 (m ≤ 9), h = 4 (m ≤ 7); our recheck: h = 3, m = 8, 491 plain-LP holes, 0 survive. Plain LP (no parity) first fails at m = 6: columns {1,2,5,6,7,8}, D = {−3,−2,0,2,5,6} (unique fractional solution: ½ on 12 cells, each diagonal split across an odd and an even row; all 64 parity choices infeasible). Sum test fails at m = 3 ({1,3,5}, D = {−1,1,3}). Reading: parity seems to be the only integrality gap that holes add. Not a closed formula (search over 2^m parity choices). General R, C: exact for N ≤ 8, m ≤ 5.
- **Starting lemma** (square board: Landau ⇒ parity test passes): strictly weaker than the conjecture (a witness's own parities work). Holds for n ≤ 12, tight cuts included, but only checked via real placements. Direct search over all a for n ≤ 8: every D has a working a; only the all-same-parity D = {−(n−1), −(n−3), …, n−1} has exactly one.
- **Peeling lemma, top row** (subagents, scripts /home/claude/agents/cell/, /home/claude/agents/dual/): on rows-{1…m} boards passing the parity test, some top-row cell always peels (keeps the test passing): h ≤ 3 with m ≤ 7, and h = 2 with m = 8; general R, C for N ≤ 8, m ≤ 5. The peel can always be chosen to keep the same parity choice a (some passing a works; not every passing a: m = 6, h = 3, C = {1,3,4,7,8,9}, D = {−3,−1,2,3,4,6}). Fact: cell e has weight 1 at some vertex of the a-restricted LP ⇔ the a-restricted LP with e's row, column and diagonal deleted is feasible; so "some a has a weight-1 vertex" is equivalent to the peeling lemma.
- **The two ends.** Most 3-cycles: unique valid D, C_n = {−⌊n/2⌋…⌊n/2⌋} (0 removed for n even); solved by F1 (n even, 2 4 6 … 1 3 5) and Skolem / hooked Skolem involutions (n odd, fixed point n or n−1). Fewest 3-cycles without a tight cut: P_n (formula above). Both explicit witnesses are two interleaved step-2 staircases (F1 ascending; P_n descending plus two corner points). Map: centre, oddcentre, pn.
- Witness counts multiply across tight blocks (n ≤ 8, E7).
- Every sequence has a removal after which every smaller witness extends by one insertion (n ≤ 7, E4).
- **Best-witness lifts** (connect agent 2026-11-23, /home/claude/agents/connect/conn_gen.c, all valid D, all general minimal moves, n ≤ 12): some witness of D lifts to D′ by changing ≤ 4 rows (≤ 3 if neither side has a tight cut, n ≥ 6); a pure column swap (a-point in row i, b-point in row i−(b−a−1)) works for 93% of moves and all 3-apart moves. Witness graphs are NOT connected under k-point rearrangements for any fixed k (P_n's two witnesses differ in every row); 3-cycle graph disconnected for every D at n ≥ 7.
- Greedy Robin Hood lifts need ≤ 4 swaps through n = 12 (E11); good witnesses aren't closed under moves (E10).
- **Capacity bound (loose lead).** P_D(x) = per(M), M_ij = x_{j−i} for j−i ∈ D. cap(P_D) = inf_{x>0} P_D/∏x_d; Li–Yao ⇔ cap > 0. W(D) ≥ (n!/nⁿ)·cap(P_D) holds for all no-tight-cut D, n ≤ 8, with 5–12× slack (Gurvits would give it if P_D were real stable; it isn't). Extended (capacity agent 2026-11-22): holds for all no-tight-cut D with n ≤ 11, worst slack 13.8, 17.2, 18.0 at n = 9–11 (near-regular D, not P_n); along P_n (W = 2) slack grows ~e^{0.21n} to n = 20. P_D is not log-concave or Lorentzian (already D = {−1,0,1}), so AOV/Gurvits don't apply. Gurvits' one-variable step fails at n = 5 (P₅, every order); best per-step constant 0.5, 0.39, 0.33, 0.33, 0.26, 0.22 (n = 4–9) (capstep agent). Any proof of the inequality (even with cⁿ) proves the conjecture. Note: the problem is a 3-way matching (rows, columns, diagonals), where such bounds fail in general, so a proof must use diagonal = column − row.

- **Bounded slack, all n** (Devin 2026-11-23, agents/interface/slack_dfa.cpp): if all σ_k ≤ B the interface walk lives in a finite automaton A_B independent of n. Complete search: A_B accepts every valid word for B ≤ 16 (22,358 determinised states at B = 16; B = 17 needs a wider state encoding than 64 bits and more than 7 GB). So **every valid D of any size with all Landau slacks ≤ 16 has a witness** (covers all n ≤ 11, and P_n plus any 15 minimal moves for every n). After a few letters e = 0 every pair of partitions of σ is reachable (B ≤ 8: at most 7 zeros from any reachable set; flat.py). Map: slack16, slackB.
- **Each diagonal at most twice** (Devin 2026-11-23, agents/interface/twice.cpp, slack_dfa2.cpp): multisets d_1 ≤ … ≤ d_n with the Landau sums and no value used more than twice always have a permutation: exhaustive n ≤ 15 (174,292,169 multisets at n = 15), and all n with slack ≤ 12. With triples Landau fails at n = 6 ({−2³, 2³}); failures for n = 6…10: 1, 6, 32, 145, 634, all with a value used ≥ 3 times. Answers the side question in §5 Saturation: no gap with multiplicities ≤ 2 for n ≤ 15. Map: twice, thrice.

## 4. Open lines

- 4.2 Ejection chains: deterministic chain rule for minimal moves that terminates. Must allow chain length to grow (see §5 repair radius).
- 4.3 Insertion after removal (paused): standard removal rule fails 9 of 21 at n = 7.

- 4.6 Peeling / parity LP. Proof shape: (starting lemma) Landau on the square board ⇒ parity test passes; (peeling lemma) a board passing the parity test has a top-row cell whose peel keeps it passing; induction ⇒ placement. Peeling the top row keeps rows an interval, so only column holes ever appear. Both lemmas hold in tests (§3).
